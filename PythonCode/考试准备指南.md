## 📅 第一阶段：填空题满分（死记硬背 + 代码理解）
填空题考查的是核心逻辑的实现细节。请务必记住以下代码片段：

1. **N皇后安全判断**：`if c == col or abs(row - r) == abs(col - c):`
2. **快速排序划分**：`left = [x for x in a[1:] if x <= pivot]`
3. **0/1背包转移方程**：`dp[i][c] = max(dp[i][c], dp[i - 1][c - weights[i - 1]] + values[i - 1])`
4. **最长公共子序列(LCS)**：`if x[i-1] == y[j-1]: dp[i][j] = dp[i-1][j-1] + 1`
5. **活动选择排序依据**：`items = sorted(items, key=lambda x: x[1])` (按结束时间排序)

## 🧠 第二阶段：编程大题核心算法（分类掌握）

### 1. 递归与分治 (Divide and Conquer)
*   **阶乘**：`fact(n) = n * fact(n-1)`，递归出口 `n <= 1`。
*   **二分查找**：有序数组，关键是 `mid = (left + right) // 2` 和指针移动。
*   **归并排序**：先分两半，再用 `merge` 函数合并两个有序表。
*   **快速排序**：选基准(pivot)，分左右，递归合并。时间复杂度 $O(N \log N)$。

### 2. 贪心算法 (Greedy)
*   **活动选择**：**必须按结束时间升序排序**。每次选不冲突且最早结束的。
*   **哈夫曼树**：每次选两个权值最小的合并，计算带权路径长度(WPL)。

### 3. 动态规划 (Dynamic Programming)
*   **0/1背包**：`dp[i][c]` 表示前 `i` 个物品在容量 `c` 下的最大价值。
*   **LCS**：`dp[i][j]` 表示字符串1前 `i` 个字符和字符串2前 `j` 个字符的最长公共子序列长度。

### 4. 回溯法 (Backtracking)
*   **N皇后**：按行放置，检查列冲突和对角线冲突。
*   **子集和**：递归尝试每个数字，若 `current_sum > target` 则剪枝(break)。

### 5. 分支限界法 (Branch and Bound)
*   **简单装载**：使用**队列**实现广度优先搜索，不断更新当前最优重量。

## 📚 第三阶段：理论与复杂度（抢分必看）

### 1. TSP (旅行商问题) 与 NP完全性
*   **问题描述**：寻找一条经过所有城市且总距离最短的回路。
*   **判定形式**：给定距离 $d$，是否存在一条回路长度 $\le d$？
*   **NP完全性理由**：
    1.  **属于NP**：给定一个路径证书，可以在多项式时间内验证其长度是否 $\le d$。
    2.  **NP难**：它是哈密顿回路问题的扩展，其他NP问题都可以规约到它。
    3.  因此，它是NP完全问题。

### 2. 时间复杂度总结
| 算法 | 平均时间复杂度 | 策略 |
| :--- | :--- | :--- |
| 二分查找 | $O(\log N)$ | 分治 |
| 快速排序 | $O(N \log N)$ | 分治 |
| 归并排序 | $O(N \log N)$ | 分治 |
| 0/1背包 | $O(N \times Cap)$ | 动态规划 |
| LCS | $O(M \times N)$ | 动态规划 |
| N皇后 | $O(N!)$ | 回溯 |
| 活动选择 | $O(N \log N)$ | 贪心 |
