**1. 设计快速排序算法**
选取首元素或末元素为基准，使用双指针把小于等于基准的元素放左侧、大于等于基准的元素放右侧，基准归位后递归处理左右子区间。
**时间复杂度**：平均 O(nlogn)，最坏 O(n²)。
**Python 伪代码**：
```python
def quick_sort(a, l, r):
    if l >= r: return
    p = partition(a, l, r)
    quick_sort(a, l, p - 1)
    quick_sort(a, p + 1, r)
```

**2. 设计分支限界算法求解 0/1 背包最大价值**
状态结点记录层号 i、当前重量 w、当前价值 v 和价值上界 bound。上界可用剩余物品的分数背包贪心估计；用优先队列按 bound 从大到小取活结点。扩展“取/不取”当前物品，若重量不超过容量则更新 best；若 bound <= best 则剪枝。
**标准答案**：搜索结束返回 best。

**3. 设计贪心算法求最多相容活动集合**
将活动按结束时间非降序排序，维护 last_end 表示已选活动的结束时间；依次扫描活动，若 start >= last_end 则选择该活动并更新 last_end。
**理由**：选择最早结束的可行活动能给后续活动留下最大剩余时间，满足贪心选择性质。
**时间复杂度**：O(nlogn)，扫描 O(n)。

**4. 设计回溯算法求给定集合中和为目标值 t 的所有子集**
用 dfs(index, total, path) 表示考察到第 index 个元素、当前和为 total、已选元素为 path。若 total == t，记录 path；若 index == n 或 total > t 则返回。否则先选择 nums[index] 递归，再撤销选择并递归不选。
**剪枝条件**：若元素非负，可用 total > t 剪枝。

**5. 设计回溯算法求解 n 皇后问题**
按行放置皇后，cols[row] = col 记录每行皇后列号。放置 (row, col) 前检查此前每个 (r, c)：c != col 且 abs(row - r) != abs(col - c)。若 row == n 则得到解；否则枚举当前行所有列，可行则递归下一行，失败后撤销。
**时间复杂度**：最坏 O(n!)。

**6. 设计二分查找算法**
初始化 left = 0, right = n - 1；当 left <= right 时取 mid = (left + right) // 2。若 a[mid] == target 返回 mid；若 a[mid] < target，令 left = mid + 1；否则 right = mid - 1。循环结束返回 -1。
**时间复杂度**：O(logn)，空间 O(1)。

**7. 设计快速排序主函数**
主函数调用 quick_sort(a, 0, len(a) - 1)，划分函数返回基准位置，再递归排序左右区间。测试样例 [5, 2, 7, 1, 4] 输出 [1, 2, 4, 5, 7]。
**时间复杂度**：平均 O(nlogn)，最坏 O(n²)。

**8. 二分查找的循环不变式**
**循环不变式**：若目标值存在，则一定在闭区间 [left, right] 中。比较 mid 后排除不可能包含目标的一半区间，并保持不变式成立。当 left > right 时区间为空，目标不存在，返回 -1。

**9. 设计动态规划算法求 0/1 背包最大价值**
定义 dp[i][c] 为前 i 件物品、容量 c 时的最大价值。
**转移方程**：不选第 i 件 dp[i][c] = dp[i-1][c]；若 c >= w[i-1]，取 max(dp[i][c], dp[i-1][c-w[i-1]] + v[i-1])。初始 dp[0][c] = 0。
**复杂度**：O(nC)。

**10. 给出子集和回溯算法的 Python 主要函数**
```python
def subset_sum(nums, target):
    ans, path = [], []
    def dfs(index, total):
        if total == target:
            ans.append(path[:]); return
        if index == len(nums) or total > target:
            return
        path.append(nums[index])
        dfs(index + 1, total + nums[index])
        path.pop()
        dfs(index + 1, total)
    dfs(0, 0)
    return ans
```
样例 [2, 3, 5, 7] 目标 10 得到 [2, 3, 5] 和 [3, 7]。

**11. 设计哈夫曼树构造算法并计算 WPL**
将所有权值放入小根堆；每次取出两个最小权值 x、y，合并为 x + y 并累加到 WPL，再把 x + y 放回堆。堆中只剩一个结点时结束。
**时间复杂度**：O(nlogn)。

**12. 说明哈夫曼树贪心构造的关键步骤**
1. 初始化小根堆；2. 循环 n - 1 次，每次弹出两个最小权值，生成父结点，父权值重新入堆。
**伪代码**：`heapify(w); ans = 0; while len(heap) > 1: a=pop(); b=pop(); ans+=a+b; push(a+b); return ans`。

**13. 设计归并排序算法**
若序列长度 <= 1 直接返回；否则取中点分为左右两半，递归排序左右子序列，再用双指针合并两个有序序列。合并时每次取较小元素加入结果，最后追加剩余部分。
**时间复杂度**：O(nlogn)，空间 O(n)。

**15. 给出二分查找的 Python 函数**
```python
def binary_search(a, target):
    left, right = 0, len(a) - 1
    while left <= right:
        mid = (left + right) // 2
        if a[mid] == target: return mid
        elif a[mid] < target: left = mid + 1
        else: right = mid - 1
    return -1
```

**19. 描述旅行商问题的判定形式及属于 NP 的理由**
**判定形式**：给定带权完全图和界 K，是否存在一条经过每个城市恰好一次并回到起点、总长度不超过 K 的回路。
**理由**：若给出一条回路，可在多项式时间内验证是否访问所有城市一次并计算总长度是否 <= K，因此属于 NP。

**20. 设计动态规划算法求最长公共子序列长度**
定义 dp[i][j] 为 x 前 i 个字符与 y 前 j 个字符的 LCS 长度。
**方程**：若 x[i-1] == y[j-1]，dp[i][j] = dp[i-1][j-1] + 1；否则 dp[i][j] = max(dp[i-1][j], dp[i][j-1])。
**复杂度**：O(mn)。

**27. 给出活动选择贪心算法的 Python 主要函数**
```python
def activity_select(items):
    items.sort(key=lambda x: x[1])
    ans = []
    last_end = -1
    for start, end in items:
        if start >= last_end:
            ans.append((start, end))
            last_end = end
    return ans
```
