1. 设计贪心算法求最多相容活动集合，并说明排序依据。要求给出算法思想、关键步骤和Python伪代码。
def activity(acts):
    # acts为[(1,3),(2,4),(5,6)]形式
    last_end_time = 0
    ans = []
    for start,end in acts:
        if start >= last_end_time:
            ans.append((start,end))
            last_end_time = end
    return ans
贪心法，按照活动结束时间升序，每次选最早结束的活动，就能保证能够参加完这个活动剩余的时间最长

2. 设计回溯算法求给定集合中和为目标值t的所有子集。要求给出算法思想、关键步骤和Python伪代码。
def solve(arr, t):
    # arr是个集合 目标值为t
    ans = []
    arr.sort() # 升序排序

    def backtrack(start_index,path,current_sum):
        if current_sum==t:
            ans.append(path[:])
        for i in range(start_index, len(arr)):
            if current_sum + arr[i] > t:
            ```如果目前加出来的值超过了目标值 说明后面的肯定也超过，就可以剪枝```
                break
            path.append(arr[i])
            backtrack(i,path,current_sum + arr[i])
            path.pop()  # 回溯
    backtrack(0,[],0)
    return ans

回溯算法，从第一个元素开始，每次携带之后的一个数字进行累加，加到了最后就进行回溯，如果加的过程中加出来的数字超过了目标值 说明后面的肯定也超过，就可以剪枝

4. 设计二分查找算法，在有序列表中查找指定元素并返回其下标。要求给出算法思想、关键步骤和Python伪代码。
def solve(arr, t):
    left,right = 0,len(arr)-1
    while(left < right):
        mid = (left+right) / 2
        if arr[mid] == t: return mid
        elif arr[mid] > t:
            right = mid-1
        else:
            left = mid+1
    return -1  # 如果没有找到 返回-1

二分查找法，关键步骤为根据mid与t的比较结果计算左右指针的值

5. 设计快速排序算法，说明划分过程并完成排序。要求写出主要函数、测试样例和时间复杂度。
def quick_sort(arr):
    if len(arr)==1:
        return arr
    povit = arr[0] # 选择第一个元素作为基准值
    left = [x for x in arr[1:] if x <= povit]
    right = [x for x in arr[1:] if x > povit]
    return quick_sort(left) + [povit] + quick_sort(right)

quick_sort([2,4,1,3,4,5,6,7])
时间复杂度为: 0(NlogN)
